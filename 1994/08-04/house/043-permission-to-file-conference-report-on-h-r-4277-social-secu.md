# PERMISSION TO FILE CONFERENCE REPORT ON H.R. 4277, SOCIAL SECURITY ADMINISTRATIVE REFORM ACT OF 1994

**Speaking:** Gibbons, Sam (G000153) [D-FL]

**Measures:** H.R. 4277

```
[Congressional Record: August 4, 1994]
From the Congressional Record Online via GPO Access [wais.access.gpo.gov]

 
  PERMISSION TO FILE CONFERENCE REPORT ON H.R. 4277, SOCIAL SECURITY 
                   ADMINISTRATIVE REFORM ACT OF 1994

  Mr. GIBBONS. Mr. Speaker, I ask unanimous consent that the managers 
may have until midnight tonight to file a conference report on the bill 
(H.R. 4277) to establish the Social Security Administration as an 
independent agency and to make other improvements in the Old-Age, 
Survivors, and Disability Insurance Program.
  The SPEAKER pro tempore. Is there objection to the request of the 
gentleman from Florida?
  There was no objection.
```
