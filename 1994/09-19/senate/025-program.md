# PROGRAM

**Speaking:** Mitchell, George J. (M000811) [D-ME]

```
[Congressional Record: September 19, 1994]
From the Congressional Record Online via GPO Access [wais.access.gpo.gov]

 
                                PROGRAM

  Mr. MITCHELL. In the meantime, pursuant to the prior agreement, the 
Senate will return to the Mauz nomination at 10:30 tomorrow and there 
will be a vote on that matter, if by voice vote, in the morning; if by 
rollcall vote, at 2:15 p.m. By that time, I hope a decision will have 
been reached on this matter and we can bring this to a conclusion.
  Following that, the Senate has many important measures to take up, 
including several appropriations bills on which action must be 
completed by the end of this fiscal year. Senators should be prepared 
for lengthy sessions, with votes possible at any time from now through 
the day on which the Congress finally adjourns for the year.
```
